# Desktop Toolkit 1.9.18

## 安全修复

- 云端笔记同步现在严格验证笔记 ID 和附件路径，阻止路径穿越、越界读取及删除。
- P2P 接收与拒绝控制消息加入端到端 HMAC 认证，房间参与者无法伪造传输确认。
- Cloudflare 中继房间号最低提高到 8 位，并增加消息大小和连接速率限制。
- 局域网共享访问密码最低提高到 16 位，新增高强度随机密码生成与复制按钮。
- macOS 临时文件清理仅处理当前用户拥有的普通文件。
- 自动更新会复检每次重定向及最终下载域名，并拒绝执行名称或类型异常的安装包。

## 兼容性说明

- P2P 双方以及局域网共享双方建议同时升级至 1.9.18。
- 旧的少于 16 位局域网共享密码需要重新设置。
- Cloudflare Worker 需要重新部署，才能启用新的房间长度、消息大小与速率限制。
