# Desktop Toolkit 1.9.6

## 新功能
- **卸载软件**：列出本机已安装程序，调用官方卸载程序；可选清理残留 Uninstall 注册表项与空的 Software 产品键
- 卸载列表显示各软件图标，便于查找
- 侧栏导航增加图标；清理与卸载使用不同图标
- 悬浮菜单增加局域网共享 / 跨网传文件 / 卸载软件入口

## 调整
- 天气播报仅从悬浮菜单移除，首页卡片保留
- 悬浮菜单增加局域网 / 跨网 / 卸载入口（悬浮机器人仍应在 Windows / macOS / Linux 显示）

## 发布包
- Windows：安装包 + 便携 zip
- macOS：dmg + zip
- Linux：x86_64 便携 zip
