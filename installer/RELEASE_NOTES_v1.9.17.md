# Desktop Toolkit 1.9.17

> 局域网文件共享请仅在可信家庭/办公网络中启用；不要在公共 Wi-Fi 或不可信同网段环境使用。

## 修复

- 修复局域网共享已启动、其他电脑仍连接超时的问题：安装器可创建仅限本地子网的 Windows 防火墙入站规则。
- 局域网界面新增“放行防火墙”，支持自定义端口，并优先显示推荐连接 IP，避免误用 VPN 或虚拟网卡地址。
- 局域网文件请求绕过系统/VPN HTTP 代理，避免私有 IP 被代理后连接失败。
- 更新检查增加 GitHub 发布页和 `VERSION` 文件备用通道；GitHub API 不可用时仍可发现新版。
- 更新检查成功时减少一次重复 API 请求，缩短等待时间。

## 安全加固

- 升级 `idna` 至 3.15、Qt 运行库至 6.11.2，并将发布构建工具固定到已修复版本。
- 应用户要求完整移除远程控制及 RustDesk 相关代码、入口与打包资源。
- 移除局域网文件 API 的任意来源 CORS，取消内置默认密码。
- 局域网文件共享升级为 HTTPS，并用密码派生认证绑定临时证书；密码不再通过网络发送。
- P2P 文件传输加入独立密钥派生的 AES-GCM 端到端加密；Cloudflare 中转只能看到密文。
- P2P 同时强制校验声明大小、分块顺序、SHA-256 和最终认证标签。
- 压缩包解压增加文件数量、单文件大小、总展开大小和磁盘空间限制。
- 阻止笔记链接标题读取访问本机、私有网段和云元数据地址。
- Google OAuth 固定使用官方认证端点，阻止恶意客户端 JSON 窃取令牌。
- Node 与 VC++ 运行库下载增加来源完整性或数字签名校验；发布依赖和 Inno Setup 固定版本。
