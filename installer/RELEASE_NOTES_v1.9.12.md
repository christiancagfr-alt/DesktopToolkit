# Desktop Toolkit 1.9.12

## 新功能：粉碎文件（类似 Eraser）
- **安全粉碎**：按设定次数覆盖写入后直接删除，**不进回收站**
- **默认 3 次**覆盖（零填充 → 满填充 → 随机），可在 1–35 次间调整；可选粉碎前随机改名
- **悬浮机器人拖拽**：把文件/文件夹拖到桌面机器人上即可进入粉碎确认
- **资源管理器右键**：安装时可勾选「用 Desktop Toolkit 粉碎」；便携版也可在粉碎页内开启/关闭
- **主界面**：媒体与系统 → 粉碎文件；支持拖入队列、进度与日志
- 命令行：`DesktopToolkit.exe --shred "文件路径"`（已运行时会转交到现有实例）

## 发布包

- macOS：dmg + zip
