# Desktop Toolkit 1.9.2

## 修复与改进
- **跨网传文件页**：握手配置区更紧凑，可滚动，减少拥挤
- **内嵌面板**：局域网 / 跨网页在主窗口内不再可拖动
- **板块切换**：切换时预加载相邻页，减少卡顿
- **歌词颜色**：支持「自定义」取色并记忆
- **Cloudflare 握手**
  - 检测账号 / 拉取链接改用信号回传，不再卡在「正在检测…」
  - 一键新建：自动查找或下载便携 Node.js，并用 Token 部署
  - 多账户时优先选已有 Workers 的账户
  - 部署前自动创建缺失的 `workers.dev` 子域
  - 更清晰的鉴权与 Account ID 格式提示

## 发布包
- Windows：安装包 + 便携 zip
- macOS：dmg + zip
- Linux：x86_64 便携 zip
