# Desktop Toolkit 1.9.11

## 修复（macOS 重点：截图 / 录屏）
- **录屏导出白屏**：捕获前检测屏幕录制权限；空白帧不再写入视频，连续空白则中断并提示开启「屏幕录制」权限
- **录制卡住**：预览/录制循环不再每帧调用慢速 `screencapture` 回退（此前无权限时会卡死 UI）
- **工具栏打不开 / 无法退出**：macOS/Linux 悬浮控制条与截图遮罩改用可点击的 `Window` 标志（`Qt.Tool` 在失焦时收不到点击）
- **截图功能不可用**：空白画面检测 + `screencapture` / Qt 多显示器回退；失败时弹出权限引导
- 打包写入 Info.plist 麦克风与屏幕捕获用途说明；启动录制前请求系统屏幕录制授权对话框

- macOS：dmg + zip
