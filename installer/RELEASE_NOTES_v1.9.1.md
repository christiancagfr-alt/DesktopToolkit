# Desktop Toolkit 1.9.1

## 修复
- **录屏有画面没声音**：保存封装时无限 `-af apad` 会卡住超时，随后静默回退成「仅视频」。已改为有时限填充 / 最短对齐，并校验成品是否含音轨。
- **麦克风打开更稳**：按设备原生采样率与声道尝试打开，减少选了麦克风却录不到的情况。

## 改进
- **录屏设置记忆**：分辨率、帧率、筛选、目标、麦克风/系统声、指针高亮、画笔、保存目录会写入本地状态并在下次打开还原。
- **文件整理默认自定义**：默认分类方式为「自定义分段」（分隔符 `-`，取第 3 段）。

## 发布包
- Windows：安装包 `.exe` + 便携包 `.zip`
- macOS：`.dmg` + `.zip`（拖到「应用程序」）
- Linux：`linux-x86_64` 便携 zip（解压后运行 `DesktopToolkit`；建议 X11）
