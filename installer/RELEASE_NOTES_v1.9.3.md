# Desktop Toolkit 1.9.3

## 修复与改进
- **局域网文件共享**
  - 选中文件后点「下载选中」可后台异步下载，进度条 + 活动日志可见
  - 支持保存 / 切换连接配置（IP、端口、密码等）
  - 记住保存目录（更改目录 / 打开目录），不必每次弹窗
  - 复制本机分享链接；本机 `127.0.0.1` 自动改用局域网 IP
  - 中文文件名下载已验证
- **功能切换更流畅**
  - 空闲时预加载各功能页
  - 传输页内局域网 / 跨网 / 远程改为按需加载，减轻首次卡顿

## 发布包
- Windows：安装包 + 便携 zip
- macOS：dmg + zip
- Linux：x86_64 便携 zip
